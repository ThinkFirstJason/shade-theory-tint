# Shade Theory Window Film — Website Concept

Website mockup for a fictional window tint shop in Phoenix, AZ. Bright desert glare where the only dark objects are film, with an interactive VLT slider that shows heat rejection and Arizona legality.

**Live:** https://thinkfirstjason.github.io/shade-theory-tint/

- Single static `index.html`, no build step
- Design language for reuse: [DESIGN.md](DESIGN.md)
- Photos from [Unsplash](https://unsplash.com) (Unsplash License)

Fictional business. Names, addresses and phone numbers are made up. Tint law and film figures are approximations, not legal advice.
